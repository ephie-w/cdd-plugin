# CDD discovery

When a request might reuse a CDD pattern, component, standard, or service, use `/cdd-core:discover` before recommending adoption. Keep the answer grounded in the bundled catalogue. A `draft` pattern or `candidate` component is not approved. A plugin listed in the marketplace's `optionalPlugins` is not necessarily installed. When an optional component plugin is missing, give the discover skill's installation handoff and mark its assessment skill as not run; do not substitute a manual reading of that skill's repository copy.
