# CDD discovery

When a request might reuse a CDD pattern, component, standard, or service, use `/cdd-core:discover` before recommending adoption. Start from the bundled catalogue, then read its relevant authoritative sources before making source-specific claims. A `draft` pattern or `candidate` component is not approved. A plugin declared by the marketplace is not necessarily active in the current session. When a component plugin is missing, give the discover skill's installation handoff and mark its skill as not run; do not substitute a manual reading of that skill's repository copy.
