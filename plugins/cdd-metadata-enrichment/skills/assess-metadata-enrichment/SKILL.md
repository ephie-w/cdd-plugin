# Assess Metadata Enrichment fit

This demo skill evaluates fit only; it does not integrate with or call the service.

Confirm the project needs structural, semantic, temporal, business, or source metadata before indexing. Ask whether the Metadata team has deployed the project's configuration; if not, flag that prerequisite. Report the service as a `candidate`, not an approved component. For real implementation, consult the authoritative service repository and organisational onboarding documentation before making technical claims or code changes.
