# README hygiene

Available as `/docs-and-release:readme-hygiene`.

## Steps

1. Follow the README's own setup instructions in a clean environment and note
   every step that fails or is missing.
2. Verify claims against the code: commands, config file names, supported
   versions, badges, links.
3. Check structure: what the project does (first paragraph), quickstart,
   configuration, contributing, license.
4. Propose a diff that fixes inaccuracies first, then improves structure —
   don't rewrite voice or style wholesale.
